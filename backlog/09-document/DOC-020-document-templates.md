## Description

Templates (e.g. 'Contoso Brief') define page settings, styles, header/footer and starter blocks.
Templates can be published by an org design system and appear on the Start screen.

## Acceptance criteria

- [ ] Creating a document from a template copies structure and links styles
- [ ] Org design systems can publish templates
- [ ] Templates show in the Start screen 'From design system' list
