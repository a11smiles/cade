## Description

`SECURITY.md` with supported versions, how to report (GitHub private vulnerability reporting enabled), response targets (acknowledge in 3 business days), coordinated disclosure, and GitHub Security Advisories for fixes with CVEs where applicable.

## Acceptance criteria

- [ ] Private vulnerability reporting is enabled on the repo
- [ ] SECURITY.md states supported versions and response targets
- [ ] Advisory workflow is documented for maintainers
