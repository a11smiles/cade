## Description

Provide keyboard navigation between resources and connections, an accessible outline of containers and resources, and announcements for staged changes.

## Acceptance criteria

- [ ] Tab and arrow keys move between resources in a logical order
- [ ] Screen readers announce resource type, name and container
- [ ] Connections can be created from the keyboard
