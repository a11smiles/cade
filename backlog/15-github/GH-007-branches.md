## Description

Branch from any version, switch branches and see which branch the canvas shows. Branch names default to `cade/<topic>`.

## Acceptance criteria

- [ ] Branching from a history entry creates and switches to the branch
- [ ] Current branch shows in the header
- [ ] Switching with unsaved changes prompts to save or stash
