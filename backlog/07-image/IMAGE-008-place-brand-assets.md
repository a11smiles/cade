## Description

The brand assets tool opens a picker of logos, icons and illustrations from the linked design system with usage rules (minimum size, clear space) enforced on placement.

## Acceptance criteria

- [ ] Logos and icons from the library can be placed
- [ ] Logos below minimum size are flagged
- [ ] Clear-space rules show as a guide around the logo
