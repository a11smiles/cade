## Description

Status pill (policy, offline, budget, run state), count badge, ADD/MOD/DEL op tags, PII/Confidential classification tags and output-type tags. Each carries text so meaning never depends on color alone.

## Acceptance criteria

- [ ] Every variant includes a text label
- [ ] Pills support a leading dot or icon
- [ ] Variants pass contrast in both themes
