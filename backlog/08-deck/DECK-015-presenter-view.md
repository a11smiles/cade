## Description

When two displays are available, show the audience the slide and the presenter a view with current slide,
next slide, notes (adjustable font size), elapsed timer and slide counter. Swap displays from the view.

## Acceptance criteria

- [ ] Presenter view opens on the secondary display automatically when one is connected
- [ ] Timer can be paused and reset
- [ ] Notes font size changes persist per user
- [ ] Swap displays works without leaving present mode
