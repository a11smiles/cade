## Description

Recruit beta users across the three OSes and roles (designers, PMs, engineers, architects), ship on the beta channel, collect feedback through the in-app flow and track exit criteria for 1.0.

## Acceptance criteria

- [ ] Beta channel has at least 30 active users across all three OSes
- [ ] 1.0 exit criteria are written and tracked
- [ ] No open S1 or S2 bugs at release
